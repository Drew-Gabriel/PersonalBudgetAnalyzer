Overview

I am developing my programming skills by learning how to use R for data processing, calculations, and visualization. This project helped me practice R syntax and learn how to organize and analyze data in a useful way.

The software I created is a Personal Budget and Expense Analyzer. It uses R to store expense information, organize expenses into categories, calculate spending totals and averages, check the remaining budget, classify expenses by spending level, and create a bar chart to visualize spending by category.

The purpose of writing this software is to practice using the R programming language while creating a useful tool for analyzing personal expenses. Through this project, I learned how to work with data frames, variables, functions, lists, loops, conditional statements, and visualizations in R.

"Software Demo Video" (http://youtube.link.goes.here)

Development Environment

I developed this software using Visual Studio Code and R 4.6.1. I used R to write, run, and test the program and GitHub to store and publish the project.

The programming language used for this project is R. The program uses R's built-in data frames, functions, lists, loops, conditional statements, and base R plotting features. It also uses the dplyr package for the case_when function.
