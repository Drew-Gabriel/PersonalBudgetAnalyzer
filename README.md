Overview

I am developing my programming skills by learning how to use R for data processing, calculations, and visualization. This project helped me practice R syntax and learn how to organize and analyze data in a useful way.

The software I created is a Personal Budget and Expense Analyzer. It uses R to store expense information, organize expenses into categories, calculate spending totals and averages, and create visualizations that make the spending information easier to understand.

The purpose of writing this software is to practice using the R programming language while creating a useful tool for analyzing personal expenses. Through this project, I learned how to work with data frames, variables, functions, calculations, and visualizations in R.

"Software Demo Video" (http://youtube.link.goes.here)

Development Environment

I developed this software using Visual Studio Code and the R programming language. I used the terminal to run and test the R program and GitHub to store and publish the project.

The programming language used for this project is R. I used R's built-in data frame and data manipulation features along with the ggplot2 library to create visualizations of the expense data.
